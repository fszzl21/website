Domain Forests

Functional Levels

# Domain en Forest Functional Level bekijken
Get-ADDomain | Select DomainMode
Get-ADForest | Select ForestMode

# Verhogen naar 2016 (alleen als ALLE DCs 2016 zijn!)
Set-ADDomainMode -Identity school.test -DomainMode Windows2016Domain
Set-ADForestMode -Identity school.test -ForestMode Windows2016Forest

Functional level kan alleen omhoog, nooit omlaag. Zorg dat alle DCs hetzelfde OS-niveau hebben voor je dit doet.

AD DS Schema — ADSI Edit

# ADSI Edit openen (schema objecten bekijken/aanpassen)
adsiedit.msc

Schema aanpassen is onomkeerbaar! Doe dit alleen als het echt nodig is (bijv. bij Exchange-installatie).

LDAP Distinguished Names

# Voorbeeldnotatie distinguished name:
cn=Henk Jansen,OU=inkoop,DC=school,DC=test

# cn  = common name (gebruikersnaam)
# OU  = organisational unit
# DC  = domain component (= DNS-label)

Global Catalog

# GC-server instellen op een DC
Set-ADObject "CN=NTDS Settings,CN=DC1,CN=Servers,CN=Default-First-Site-Name,CN=Sites,CN=Configuration,DC=school,DC=test" -Replace @{options='1'}

# Controleren welke DCs GC zijn
Get-ADDomainController -Filter * | Select Name, IsGlobalCatalog

Zorg voor minimaal één GC per fysieke locatie. Exchange vereist een snelle GC-verbinding en werkt niet met RODC/ROGC.

FSMO / Operations Master rollen

Rol Aantal Bereik
Schema Master 1 Forest
Domain Naming Master 1 Forest
PDC Emulator 1 per domein Domein
RID Master 1 per domein Domein
Infrastructure Master 1 per domein Domein 
# Bekijken welke DC welke rol heeft
netdom query fsmo

# Rollen overzetten via PowerShell
Move-ADDirectoryServerOperationMasterRole -Identity DC2 -OperationMasterRole PDCEmulator,RIDMaster,InfrastructureMaster

Zonder RID Master kunnen geen nieuwe gebruikersaccounts worden aangemaakt.

Replicatie

# Replicatie direct forceren
repadmin /syncall /AdeP

# Replicatiestatus bekijken
repadmin /showrepl
repadmin /replsummary

# Diagnose
dcdiag /test:replications

Intrasite replicatie: direct, geen compressie. Intersite replicatie: 180 min interval, wel compressie.

Domain Trusts

# Trust aanmaken (expliciet, one-way)
netdom trust school.test /domain:extern.test /add /twoway

# Bestaande trusts bekijken
Get-ADTrust -Filter *

Transitive trusts worden automatisch aangemaakt tussen domeinen in hetzelfde forest. Expliciete trusts maak je handmatig aan.
