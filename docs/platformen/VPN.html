Virtual Private Networks

VPN-protocollen vergelijking

Protocol Poort/Protocol Veiligheid Opmerking
PPTP TCP 1723 + GRE 47 Onveilig Niet gebruiken
L2TP/IPsec UDP 500, 4500 + ESP 50 Goed Problemen met NAT
SSTP TCP 443 (SSL) Goed Werkt door NAT/firewall
OpenVPN UDP 1194 (of TCP) Goed Open source, flexibel
WireGuard UDP (variabel) Goed Snel, in Linux/Windows kernel

OpenVPN — Linux server instellen

# IP forwarding inschakelen
echo 1 > /proc/sys/net/ipv4/ip_forward

# Persistent maken
nano /etc/sysctl.conf
# Zet: net.ipv4.ip_forward = 1

# NAT instellen met iptables
iptables -I FORWARD -i tun+ -j ACCEPT
iptables -I FORWARD -o tun+ -j ACCEPT
iptables -t nat -I POSTROUTING -o ens160 -j MASQUERADE

# Met firewalld (Fedora/RHEL)
firewall-cmd --direct --add-rule ipv4 filter FORWARD 0 -i tun+ -j ACCEPT
firewall-cmd --direct --add-rule ipv4 filter FORWARD 0 -o tun+ -j ACCEPT
firewall-cmd --direct --add-rule ipv4 nat POSTROUTING 0 -o ens160 -j MASQUERADE

OpenVPN starten

# Server starten
sudo openvpn --config /etc/openvpn/server/server.ovpn

# Client verbinden
sudo openvpn --config client.ovpn

OpenVPN port forwarding in VyOS

set nat destination rule 10 description 'Port Forward: OpenVPN'
set nat destination rule 10 destination port '1194'
set nat destination rule 10 inbound-interface 'eth3'
set nat destination rule 10 protocol 'udp'
set nat destination rule 10 translation address '10.13.14.1'

WireGuard — Linux instellen

# Installeren
sudo apt install wireguard -y

# Sleutelpaar genereren
wg genkey | tee privatekey | wg pubkey > publickey

# Config aanmaken
nano /etc/wireguard/wg0.conf

Voorbeeldconfig server (/etc/wireguard/wg0.conf):

[Interface]
PrivateKey = <server-privatekey>
Address = 10.0.0.1/24
ListenPort = 51820

[Peer]
PublicKey = <client-publickey>
AllowedIPs = 10.0.0.2/32

# WireGuard interface starten
sudo wg-quick up wg0

# Status bekijken
sudo wg show

WireGuard slaat publieke IP's op totdat de server reboot. Als anonimiteit essentieel is, gebruik dan OpenVPN.

Windows RRAS — VPN server instellen

# RRAS-rol installeren
Install-WindowsFeature RemoteAccess, Routing, DirectAccess-VPN -IncludeManagementTools

# RRAS configureren via GUI
rrasmgmt.msc
# Rechtermuisklik op server → Configure and Enable Routing and Remote Access
# Kies: Remote Access (dial-up or VPN)

NPS (Network Policy Server) instellen

# NPS installeren
Install-WindowsFeature NPAS -IncludeManagementTools

# NPS console openen
nps.msc

NPS blokkeert standaard alle remote access. Maak een Network Policy aan:

  1. nps.msc → Network Policies → New
  2. Conditie: Windows Groups → domeingroep toevoegen
  3. Access granted
  4. Authenticatiemethode: MS-CHAPv2 of EAP

L2TP/IPsec — Pre-shared key instellen

# Via RRAS:
# Server → Properties → Security → Allow custom IPsec policy for L2TP
# Pre-shared key invullen

# Client instellen (Windows):
# Netwerk- en Internet-instellingen → VPN → Add VPN
# Type: L2TP/IPsec with pre-shared key

L2TP/IPsec werkt niet als de RRAS-server achter NAT zit — zet de server direct in een DMZ.

Authenticatieprotocollen (volgorde voorkeur)

1. EAP-TLS      (certificaten, meest veilig)
2. PEAP         (alleen servercertificaat nodig)
3. MS-CHAPv2    (gebruikersnaam + wachtwoord, minst veilig van de drie)
