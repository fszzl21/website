Windows Group Policies

Tools

# Local policy editor (alleen lokaal)
gpedit.msc

# Group Policy Management Console (domein)
gpmc.msc

# GPO direct bijwerken op een client
gpupdate /force

# GPO-status van huidige gebruiker/computer bekijken
gpresult /r

# GPO-rapport als HTML exporteren
gpresult /H C:\Reports\GPReport.html

# Remote GPUpdate via PowerShell
Invoke-GPUpdate -Computer "PC01" -RandomDelayInMinutes 0

GPO aanmaken en koppelen

# Nieuwe GPO aanmaken
New-GPO -Name "Mijn GPO" -Comment "Aangemaakt via PS"

# GPO koppelen aan een OU
New-GPLink -Name "Mijn GPO" -Target "OU=Medewerkers,DC=school,DC=test"

# GPO koppelen aan domein
New-GPLink -Name "Mijn GPO" -Target "DC=school,DC=test"

Volgorde van toepassing (L→H wint)

1. Local GPO
2. Site GPO
3. Domain GPO
4. OU GPO (van buiten naar binnen)
5. Child OU GPO (laatste schrijver wint)

Child OU-instellingen overschrijven ouder-instellingen, tenzij Enforce is ingesteld op de hogere GPO.

Block Inheritance en Enforce

# Block Inheritance instellen op een OU (via GPMC of PowerShell)
Set-GPInheritance -Target "OU=Kiosk-Computers,DC=school,DC=test" -IsBlocked Yes

# Enforce instellen op een GPO-link (hogere laag wint altijd)
Set-GPLink -Name "Default Domain Policy" -Target "DC=school,DC=test" -Enforced Yes

Enforce verslaat altijd Block Inheritance.

Loopback Processing

Loopback zorgt dat computer-GPO's ook de gebruikersinstellingen bepalen — ongeacht wie inlogt. Handig voor kiosks.

# Inschakelen via GPO:
# Computer Configuration → Policies → Administrative Templates
#   → System → Group Policy → Configure user Group Policy Loopback Processing Mode
# Kies: Enabled → Mode: Replace (volledig vervangen) of Merge (samenvoegen)

Gebruik Replace voor kiosks: dan gelden alleen de computer-GPO's, niet de gebruikersprofiel-GPO's.

Troubleshooting

# Resulterende policy bekijken (HTML rapport)
Get-GPResultantSetOfPolicy -ReportType HTML -Path C:\Reports\Results.html

# Event log controleren
eventvwr → Applications and Services Logs → Microsoft → Windows → Group Policy

# Alle GPO's in het domein bekijken
Get-GPO -All

# GPO-instellingen back-uppen
Backup-GPO -All -Path C:\GPO-Backups

# GPO herstellen vanuit backup
Restore-GPO -Name "Mijn GPO" -Path C:\GPO-Backups

Als GPO niet vernieuwd lijkt: controleer of de gebruiker uit- en ingelogd is, en of de refresh interval (standaard 90 min) verstreken is.

ADMX Central Store aanmaken

# Map aanmaken op SYSVOL
New-Item -ItemType Directory "\\school.test\SYSVOL\school.test\Policies\PolicyDefinitions"

# ADMX-bestanden kopiëren vanuit Windows
Copy-Item "C:\Windows\PolicyDefinitions\*" "\\school.test\SYSVOL\school.test\Policies\PolicyDefinitions\" -Recurse

Eenmalig per domein. Daarna gebruiken alle beheermachines automatisch de centrale ADMX-bestanden.
