Windows Systeembeveiliging & PKI

Windows Firewall met Advanced Security

# Firewall-regels bekijken
Get-NetFirewallRule | Where Enabled -eq True | Select DisplayName, Direction, Action

# Inbound regel toevoegen (poort 443 toestaan)
New-NetFirewallRule -DisplayName "HTTPS inbound" -Direction Inbound -Protocol TCP -LocalPort 443 -Action Allow

# Poort blokkeren
New-NetFirewallRule -DisplayName "Blokkeer poort 8080" -Direction Inbound -Protocol TCP -LocalPort 8080 -Action Block

# Regel verwijderen
Remove-NetFirewallRule -DisplayName "HTTPS inbound"

Profielen: Domain (binnen het domein), Private (thuis/kantoor), Public (onbekend netwerk). Stel afzonderlijke regels in per profiel.

IPsec Connection Security Rules (via GPO)

# Via Group Policy:
# Computer Configuration → Windows Settings → Security Settings
#   → Windows Firewall with Advanced Security → Connection Security Rules

# Typen:
# Isolation       — authenticatie vereisen van domeinleden
# Authentication Exemption — uitzonderingen (bijv. printers)
# Server-to-Server — specifieke hosts
# Tunnel          — site-to-site

IPsec vereist dat beide kanten domeinlid zijn (Kerberos) of een certificaat hebben. Werkt slecht samen met NAT.

AppLocker instellen

# Via GPO:
# Computer Configuration → Policies → Windows Settings → Security Settings → AppLocker

# Via PowerShell: standaardregels aanmaken
Get-AppLockerPolicy -Effective | Set-AppLockerPolicy -Merge
New-AppLockerPolicy -RuleType Publisher, Path, Hash -User Everyone -Optimize

Stel altijd standaard "allow" regels in voor Windows-mappen, anders kunnen gebruikers niets meer uitvoeren.

Certificate Authority installeren (AD CS)

# AD CS rol installeren
Install-WindowsFeature ADCS-Cert-Authority -IncludeManagementTools

# Enterprise Root CA configureren
Install-AdcsCertificationAuthority `
  -CAType EnterpriseRootCa `
  -CACommonName "School-Root-CA" `
  -KeyLength 2048 `
  -HashAlgorithmName SHA256 `
  -ValidityPeriod Years `
  -ValidityPeriodUnits 10

Enterprise CA integreert met AD en ondersteunt autoenrollment. Standalone CA werkt zonder AD maar vereist handmatige uitgifte.

Certificaattemplate aanmaken

# Via GUI (certtmpl.msc):
# 1. Bestaande template dupliceren (bijv. "Computer" of "User")
# 2. Naam aanpassen, geldigheidsperiode instellen
# 3. Security tab: groep toevoegen → "Enroll" en "Autoenroll" rechten geven
# 4. Template publiceren in CA:
#    certsrv.msc → Certificate Templates → New → Certificate Template to Issue

Autoenrollment instellen via GPO

# Via GPO:
# Computer Configuration → Policies → Windows Settings → Security Settings
#   → Public Key Policies → Certificate Services Client – Auto-Enrollment

# Instellen op:
# Enabled
# Renew expired certificates: aan
# Update templates: aan

Autoenrollment werkt alleen met Enterprise CA en als de gebruiker/computer "Autoenroll"-rechten heeft op het template.

Certificaat handmatig aanvragen

# Via certmgr.msc (gebruiker) of certlm.msc (computer):
# Personal → Certificates → rechtermuisklik → All Tasks → Request New Certificate

# Via command line:
certreq -new request.inf request.csr
certreq -submit -attrib "CertificateTemplate:WebServer" request.csr response.cer
certreq -accept response.cer

Certificaat intrekken (revocation)

# Via certsrv.msc:
# Issued Certificates → certificaat selecteren → rechtermuisklik → Revoke

# CRL handmatig publiceren
certutil -crl

# CRL bekijken
certutil -URL https://pki.school.test/crl/school-root-ca.crl
